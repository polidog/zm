# 旧 MS-50G への対応計画

旧 MS-50G（MS+ より前の世代）を、G2 FOUR と同じ `zoom` から扱えるようにする。
手を付けるのは Go への書き直し（[go-rewrite.md](go-rewrite.md)）の G6 が終わってから。
ただし G3 で `device` と `ops` の境目を決めるときに、ここに書く機種の差が入る余地を残しておく。

## 分かっていること

2026-10-27 に手元の旧 MS-50G へ `zoom probe --port hw:5,0` を当てた結果（エディタモードなし、読み出しのみ）。

- ALSA のポート名は `ZOOM MS Series MIDI 1`。G2 FOUR（`ZOOM G2/G2X FOUR MIDI 1`）と並べて挿せる
- Identity Reply: `f0 7e 00 06 02 52 58 00 00 00 33 2e 31 30 f7`
  - デバイス ID は **`58`**（MS+ / FOUR は `6E`）、model は `0000`、ファームウェアは **3.10**
  - 生バイトは `backups/20261027-232728-identity.syx`
- `33`（現在のプログラム番号）は SysEx の応答なし
- `64 13`（MS+ 世代の現在パッチ要求）は応答なし。別世代のコマンドなので予想どおり

## まだ確かめていないこと

下は記憶と外の資料による見込みで、実機ではまだ確かめていない。
使う前に g200kg/zoom-ms-utility の midimessage.md と突き合わせ、実機で確かめる。

- エディタモードは MS+ と同じ `50` / `51`
- 現在パッチは `29` で要求し、`28` で返る。MS+ のような 7bit パック + CRC の枠ではなく、パッチが直接入っている
- パラメータの編集は `31`、保存は `32` 系
- パッチは 50 件、1 パッチにエフェクト 6 個まで
- エフェクトは ZD2 ではなく ZDL。カタログは MS+ とは別の作り方になる
- `33` には SysEx ではなく Program Change などの普通の MIDI メッセージで返っている可能性がある。今の probe は SysEx しか待たないので取りこぼしているかもしれない

## 構成

機種の差は `device` の下と、パッチ・カタログの形式に閉じ込める。CLI・TUI・MCP は `ops` だけを見る。

```
internal/
  device/          機種を Identity の デバイス ID で選ぶ
    four/          6E: いまの実装（45/46、64 20、64 12）
    legacy/        58: 旧 MS（29/28、31、32）
  patch/           PTCF
  legacypatch/     旧 MS のパッチ形式
  catalog/         ZD2 から / ZDL から、の 2 通りの作り方。出力の形は揃える
  ops/             機種によらない操作。番号の範囲（300 件 / 50 件、スロット数）は device から受け取る
```

- `ops` が持つパッチの見え方（スロットごとのエフェクト名・ON/OFF・パラメータ）を機種によらず揃え、
  バイト列との変換は機種ごとの実装に任せる
- パッチ数・スロット数・保存の可否など、機種で違う値を決め打ちにしない。G3 の時点で `device` から受け取る形にしておく
- バックアップは機種ごとに分ける（`backups/<機種>/all-<時刻>/`）。G2 FOUR の既存のバックアップの置き場は動かさない

## 進め方

| 段 | やること | 終わりの条件 |
|---|---|---|
| L0 | probe を機種で分ける。58 なら エディタモード ON → `29` → OFF。`33` の応答を SysEx 以外も含めて見る | 旧 MS の現在パッチの生バイトが取れる |
| L1 | 全パッチの読み出しと `legacypatch` のデコード | 50 件のラウンドトリップがバイト一致、`zoom list` / `zoom show` が旧 MS で動く |
| L2 | カタログ（ZDL のエフェクト一覧とパラメータ） | `zoom effects` / `zoom effect` が旧 MS で動く |
| L3 | 編集（`31`） | エフェクト差し替え・パラメータ変更・ON/OFF が、保存せずにペダルに反映される |
| L4 | 保存と restore | G2 FOUR の「実機の確認」と同じ手順が空きパッチで通る。最初のバックアップと全件一致に戻せる |
| L5 | MCP / TUI から旧 MS を選べる | 2 台つないだまま、`--port` か機種名で切り替えて使える |

- L0〜L2 は読み出しだけで進める。ペダルに書くコマンドは L3 から
- L3 に入る前に、L1 で全パッチを退避しておく

## 決めていないこと

- 2 台を同時につないだとき、ポートを省略したらどちらを選ぶか（今は最初に見つかった ZOOM）
- 旧 MS のファイル操作（ZDL の取り出し）が SysEx でできるか。できなければカタログは外の資料から作る
- MS-60B / MS-70CDR まで広げるか。手元に実機がないので、今は MS-50G だけにする
